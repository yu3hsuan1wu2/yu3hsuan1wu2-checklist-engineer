# Agent instructions

Keep this file short. Follow pointers instead of duplicating their contents.

Read `CONTEXT.md` when domain terminology affects a decision.

## Agent skills

### Backlog
Work is tracked in GitHub Issues. Read `docs/agents/issue-tracker.md` before publishing specs or tickets.

### Triage labels
Read `docs/agents/triage-labels.md` before assigning workflow state.

### Domain docs
Read `docs/agents/domain.md` to find the authoritative domain documents.

### Checklist engineering
When designing, auditing, or field-testing an operational checklist, use `skills/checklist-engineer/SKILL.md`.

## Change discipline

Prefer one tracer-bullet behavior change per ticket. Keep the output contract stable unless an ADR explicitly changes it. Update the smallest authoritative document; do not duplicate policy.

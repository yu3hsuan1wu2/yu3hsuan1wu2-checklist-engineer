# Triage labels

Canonical workflow roles:

- `needs-triage` — the request has not been classified.
- `needs-info` — execution requires missing information or an unresolved decision.
- `ready-for-agent` — bounded and executable by an agent.
- `ready-for-human` — bounded but requires human judgment/action.
- `wontfix` — intentionally not proceeding.

These names are the intended mapping for GitHub Issues. If the labels do not yet exist in GitHub, create them before relying on label-driven workflows.

Labels represent workflow state. They do not replace acceptance criteria or blocking edges.
